为什么医疗要单独拎出来

医疗不是普通消费

  • 是刚需，不是可选
  • 没钱也得看，不然就是等死
  • 完全市场化，穷人看不起病
  • 完全免费，又容易浪费、排队、效率低

医疗兜不住，循环就断

  • 敢干的人，一场大病回到解放前
  • 想换赛道的人，医保断了不敢动
  • 市场再活，钱最后都流进医院
  • 兜底兜不住命，别的兜底都是空的
结果
钱转起来 · GDP上去 · 机会变多 · 贫困减少 · 病有所医

1 和 7

  • 十进制里：1、7 都是奇数
  • 七进制里：7 写作 10
  • 10 末位是 0，是偶数
  • 同一个 7，进制一换，奇偶就变

进制残余

  • 一周七天：七进制残余
  • 七声音阶：do re mi fa sol la si
  • 十二时辰、六十甲子：十二进制、六十进制
  • 七进制存在过，也影响了十进制
  • 但不能说明世界底层就是七进制
  • 多种进制叠加、淘汰、残留
  • 十进制胜出，但没清干净

空与一

  • 底层不是 0，也不是 1，是空
  • 0 是空的形状
  • 把 0 压扁，就成了 1
  • 1 不是凭空来的，是空被压出来的痕
  • 无中生有，空里出数

婚姻兜底

  • 男的犯错，帮女方
  • 女方犯错，帮男方
  • 不是帮对的，是帮弱的
  • 不让任何一方被彻底压死
  • 实在过不下去，法律允许离婚
  • 能过就互相兜，不能过给出口

不同语言拆分后可以互相约掉

  • 中文“一”：笔画 → 1
  • 拼音“yi” → 拆成 vii
  • 两个 i 约掉，v 自约掉 → 空
  • 空就是丨，丨就是一
  • 所以 yi → 空 → 丨 → 一
  • 一个字/词组里，含“一”或“丨”，不管挨不挨着，都能约掉
  • 但必须是完整的字或词组，不能拆散
  • 前提是：规则里“一 = 丨 = 空”
  • 换个规则，就不一定约得掉

曲线归 0

  • 阿拉伯文、蒙古文以曲线为主
  • 曲线往 0 上偏移 → 空 → 一
  • 阿拉伯文 ا（alif）：一竖 → 丨 → 空 → 一
  • 阿拉伯文 و（waw）：弯 + 尾 → 0 → 空 → 一
  • 阿拉伯文 ه（ha）：一个圈 → 0 → 空 → 一
  • 阿拉伯文 م（mim）：小圈 + 尾 → 0 → 空 → 一
  • 阿拉伯文 ع（ain）：开口弧 → 0 → 空 → 一
  • 蒙古文 ᠠ（a）：竖 + 弯 → 丨/0 → 空 → 一
  • 蒙古文 ᠡ（e）：竖 + 小弯 → 丨/0 → 空 → 一
  • 蒙古文 ᠢ（i）：竖 + 两点 → 丨/0 → 空 → 一
  • 蒙古文 ᠣ（o）：竖 + 圈 → 丨/0 → 空 → 一
  • 蒙古文 ᠤ（u）：竖 + 弯 → 丨/0 → 空 → 一
  • 竖归 丨，弯/圈/点归 0
  • 最后都归空，空就是丨，丨就是一

拆字心得

  • 拆字按偏旁部首拆
  • 拆完如果能组成一句通顺的句子，拆字结束
  • 如果组不成通顺的句子，往通假字上做偏移
  • 如果组不成通顺的句子，往一丨上做偏移
  • 然后重复拆字步骤
  • 直到组成一句通顺的句子为止
  • 句子结束的标志：寓意完整、有深意、能引起思考
  • 这种句子，往往就是作者底层的想法
  • 规则：一 = 丨 = 空 = 0
  • 闲着没事玩的，别太当真

石英表的环

  • 买了个石英表，慢了 5 分钟
  • 不是晶振不准，是分频次数的问题
  • 32768 = 2^15，分频 15 次到 1
  • 15 是奇数，除不尽，留零头
  • 零头攒起来，就是慢
  • 1 // 2 = 0，再走一次到 0
  • 0 到 32768，不震动
  • 0 和 32768 咬合上了
  • 成一个环：0 → 1 → … → 32768 → 0
  • 15 次停在 1，环没闭合
  • 16 次走到 0，环闭合
  • 环闭合，就不慢
  • 大型石英表、医院表更明显
  • 母钟偏，子钟跟着偏，一慢全慢
  • 5 分钟怎么推出来
  • 15 次分频，每圈差 1 秒
  • 每分钟 1 圈，每小时 60 圈
  • 每小时差 60 秒 = 1 分钟
  • 5 小时差 5 分钟
  • 时间越长，差得越多
  • 不是固定慢 0.5，是按分频次数推出来的量

  • LE:L ↔ 1:0

  • 两种情况能对合

  • 导致的表象不同
  • 其实还是 15 的锅
