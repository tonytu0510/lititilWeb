不同语言拆分后可以互相约掉

  • 中文“一”：笔画 → 1
  • 拼音“yi” → 拆成 vii
  • 两个 i 约掉，v 自约掉 → 空
  • 空就是丨，丨就是一
  • 所以 yi → 空 → 丨 → 一
  • 一个字/词组里，含“一”或“丨”，不管挨不挨着，都能约掉
  • 但必须是完整的字或词组，不能拆散
  • 前提是：规则里“一 = 丨 = 空”
  • 换个规则，就不一定约得掉

  • 阿拉伯文 ه（ha）：一个圈 → 0 → 空 → 一
  • 阿拉伯文 م（mim）：小圈 + 尾 → 0 → 空 → 一
  • 阿拉伯文 ع（ain）：开口弧 → 0 → 空 → 一
  • 蒙古文 ᠠ（a）：竖 + 弯 → 丨/0 → 空 → 一
  • 蒙古文 ᠡ（e）：竖 + 小弯 → 丨/0 → 空 → 一
  • 蒙古文 ᠢ（i）：竖 + 两点 → 丨/0 → 空 → 一
  • 蒙古文 ᠣ（o）：竖 + 圈 → 丨/0 → 空 → 一
  • 蒙古文 ᠤ（u）：竖 + 弯 → 丨/0 → 空 → 一

拆字心得

  • 拆字按偏旁部首拆
  • 拆完如果能组成一句通顺的句子，拆字结束
  • 如果组不成通顺的句子，往通假字上做偏移
  • 如果组不成通顺的句子，往一丨上做偏移
  • 然后重复拆字步骤
  • 直到组成一句通顺的句子为止
  • 句子结束的标志：寓意完整、有深意、能引起思考
  • 这种句子，往往就是作者底层的想法
  • 规则：一 = 丨 = 空 = 0
  • 闲着没事玩的，别太当真

石英表的环

  • 买了个石英表，慢了 5 分钟
  • 不是晶振不准，是分频次数的问题
  • 32768 = 2^15，分频 15 次到 1
  • 15 是奇数，除不尽，留零头
  • 零头攒起来，就是慢
  • 1 // 2 = 0，再走一次到 0
  • 0 到 32768，不震动
  • 0 和 32768 咬合上了
  • 成一个环：0 → 1 → … → 32768 → 0
  • 15 次停在 1，环没闭合
  • 16 次走到 0，环闭合
  • 环闭合，就不慢
  • 大型石英表、医院表更明显
  • 母钟偏，子钟跟着偏，一慢全慢
  • 5 分钟怎么推出来
  • 15 次分频，每圈差 1 秒
  • 每分钟 1 圈，每小时 60 圈
  • 每小时差 60 秒 = 1 分钟
  • 5 小时差 5 分钟
  • 时间越长，差得越多
  • 不是固定慢 0.5，是按分频次数推出来的量
