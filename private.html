无 → 一 → 天 → 日 → 月 → 星 → 辰 → 生 → 王 → 圣 → 道 → 无
天
一 + 大
至高之上，人形所立。天子管生，也管死。
火
天少一横
天塌了一层，落到人间，就是火。
雨
天 + 门 + 点
天开一门，龙从门过，水从门落。
水
坎为水
文人就是坎，文人就是水。地有缺口，水聚其中。
土
天在下，地在上
天地倒悬，百姓住在里面。
士
天在上，地在下
土倒过来就是士。读书人，就是倒过来的土。
王
三横一竖
贯通天地人者，为王。王就是天地中间站个人。
山
王的一半
山是竖起来的王。皇帝封禅，就为把另一半接上。
出
两山相叠
两个王的一半合起来，就是另一个不常见的王。
至
天 + 匕首 + 土
天子的军队到了地上。成了就是入土，败了就是埋土。
云
天 + 厶 + 地
匕首悬在天地之间，没落下来。
星
日 + 人 + 天
星就是天上的王。将星下凡，就是天命落地。
辰
山中之龙
龙王的一半，生下来是王的一半，还没成为王。
日
天之子
日就是天子，管白天，也管人命。
月
日之阴面
月是日翻过来的脸。日管生，月管死。
明
日 + 月
两个日，就是两个人说话。明朝这个名字，注定多口舌。
命
天 + 口 + 令
天开口，下命令。命不是自己的，是天上发下来的。
令
天 + 跪人
天说一句，人跪下接令。命令就是天口加跪人。
皇
白 + 王
卜卦说是王，就是皇。姓白的，最早就是干这个的。
帝
卜天曰一半
知道天意一半的人，才能称帝。另一半，皇帝也不知道。
圣
又 + 土
地上又出现一个天。所以皇帝叫圣上。
道
首 + 辶
日、月、天全倒过来了，然后走了。他走之后留下的，就是道。
巫
天 + 地 + 两人
天子与巫师，共坐天地之间。一个管人，一个管天。
祝
礻 + 兄
兄是天变的，祝就是祭天开口的师兄。
灵
山 + 天
山天相接，就是灵。所以祭天都在山上。
神
礻 + 申
天伸下来一道闪电，插进田里。古人跪下拜，就是神。
鬼
卜卦说天有武器
天上有刀，掉下来杀人。人受天罚，就是鬼。
祖
礻 + 且
日月入土，后人祭拜，就是祖。皇帝死后才叫祖。
生
土上生
天之气入土，生出万物。天子让人生，人就生。
死
歹 + 匕
生了一半，被人拿匕首挂了。天子让人死，人就死。
龙
天在东边挂宝剑
天威落地，行风动雨。龙就是天子的兽形。
凤
风中玄鸟
鸟借风力，飞成王权信使。凤求凰，就是门内求皇。
鸟
勺 + 与
下取地食，上通天气。玄鸟生商，鸟就是祖先。
文
天之所变
文人如水，水由天变。皇帝又用文人，又防文人。
一
通天
一为天，也为地，万物从它开始。
无
通天
天地未分，无中生有。最后一切又回到无。
