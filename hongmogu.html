# 笔记 2026-08-31

有些单子看起来是“生意”，实际上是“测试”。

如果你识别出来了，对方就进入了“合作模式”；
如果你没识别出来，对方就留在“试探模式”。

识别异常，比完成订单更重要。
# 笔记 2026-08-30

尺寸差几丝，图纸对不上，合同签了就挂。

不签原合同，只接“修改后”的单子。

对方如果同意改，说明他是来合作的；
如果不同意改，说明他是来设局的。
# 笔记 2026-08-29

有些陷阱不是“技术性的”，是“社会性的”。

一旦进入“打架模式”，无论输赢，你都已经输了。

不进入游戏，是唯一有效的应对方式。
# 笔记 2026-08-28

10斤驴蹄筋，呼烂一点，一个人吃完。

这个条件本身就是一条完整的“反制协议”。

它不需要被执行，它只需要被说出来。
# 笔记 2026-08-27

合作与不合作，不是“对错”之分，而是“路径”之分。

合作，进入既有系统，按规则运行——经济回报，但受限于系统边界。
不合作，留在系统外部，不按规则运行——系统设计权，但经济回报较低。

两个结果都是“对的”，只是能做的事情不同。
