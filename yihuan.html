一丨环

从“一半丨”和“一伴丨”推出来的字环

从一到十：一半丨，一伴丨

数字 一半丨 一伴丨

左边是拆，右边是合。一拆一合，字就出来了。

根本

一 · 丨

一 是横，平着，表示展开、地面、时间。

丨 是竖，直着，表示贯通、立起、上下。

一和丨相交，就成了 十。

十不是十全十美，是横竖相遇的那一个点。

一半丨，一伴丨

一半丨：把“丨”分成两半，是拆。

一伴丨：让“一”和“丨”作伴，是合。

一拆一合，就是字的生死。

卜：十少一横，旁边一点。

不：卜上加一横，右边多一点。

个：人下一竖。

人：八分开，站成两个人。

空：从一到空

空 拆开是 穴 + 工。

穴是洞，工是一横一竖一横。

工里有横有竖，竖就是丨，横就是一。

所以空不是没有，是一个洞里，放着一横一竖。

空 → 穴 + 工

工 → 一 + 丨 + 一

丨 → 1

一 → 1

所以空的最里面，还是 1。

也可以倒着推：

1 → 一

1 → 丨

一 + 丨 + 一 → 工

穴 + 工 → 空

所以空不是没有，是一和丨在洞里作伴。

空，不是无，是空间里藏着“一”。

色：一丨七

色 拆开是 ⺈ + 巴。

但也可以玩成：色 → 一 + 丨 + 7。

一横、一竖、一个 7。

7 是数字，也是七。

所以色不是色，是一丨七。

色即是空，空即是色。

色拆到最后，是一丨七；空拆到最后，是一丨一。

一个七，一个一。

七和一，都是 1。

所以色和空，最后都回到 1。

色不异空，空不异色。拆到最底，都是 1。

解法一：色空互推，1 = 7

空 → 卜丨 → 一 + 1 + 丨

色 → 一 + 丨 + 7

其中 1 = 7

所以：

空 = 一 + 丨 + 1 = 一 + 丨 + 7 = 色

也可以反着来：

色 = 一 + 丨 + 7 = 一 + 丨 + 1 = 空

色 → 空 → 色

空 → 色 → 空

1 等于 7，色空就能倒推回去。

解法二：一=1，丨=0，十=10，中=口+丨

因为空在数学上等于 0，所以：

丨 = 0

一 = 1

十 = 10

中 = 口 + 丨

口是空框，丨是 0。

所以“中”就是：

0 站在空框中间。

再推：

日 = 口 + 一 = 框里放 1

田 = 口 + 一 + 丨 = 框里放 1 和 0

由 = 田上一横出头

甲 = 田下一横出头

中、日、田，都是框里放 1 或 0。

七进制：0 到 7

这个世界，本质是 7 进制。

0、1、2、3、4、5、6、7

到 8 就是 00

到 9 就是 01

所以：

7 是满，是这一轮的终点。

1 是初，是这一轮的起点。

7 再走一步，就是下一轮的 0 或 1。

1 和 7，在环上是同一个位置。

所以：

色即是空，空即是色。

不是比喻，是进制。

1 是头，7 是尾。头尾相接，就是环。

七满进位

如果继续往下走：

8 = 00

9 = 01

10 = 9

11 = 11

12 = 12

17 = 17

18 = 100

19 = 101

20 = 20

21 = 21

27 = 27

28 = 200

29 = 201

规律是：

个位数到 7 就满，但十位数还是十进制。

所以 8、18、28 这些位置，都会重新归零。

8 是 00，18 是 100，28 是 200。

所以这套记法不是标准七进制，也不是八进制。

它是：

十进制外壳 + 七进制内核

数字还是十进制读，但“满”的定义是 7。

因此叫它：

七满进位

逢八归零，七满成环。

大环 3.0：英文字母

A=一=1 → B=0 → C=0 → D=0 → E=丨一=01=1 → F=丨=0 → G=1 → H=一=1 → I=0 → J=一7=丨=0 → K=0 → L=丨一=01=1 → M=0 → N=0 → O=0 → P=丨=0 → Q=0 → R=0 → S=0 → T=一丨=10 → U=1 → V=0 → W=0 → X=0 → Y=0 → Z=0 → A=一=1

A到Z，大多为0，少数为1，T为10。0是空，1是一，10是十。英文字母，也在一丨之间。

大环 4.0：汉字 + 英文字母

一 → 丨 → 十 → T → 10 → A → 一 → 1 → E → 丨一 → 01 → L → 丨一 → 01 → 1 → 日 → 田 → 土 → 地 → 空 → 色 → 7 → 1 → 一

一 → 丨 → 十 → T → 10 → A → 一 → 1 → E → 丨一 → 01 → L → 丨一 → 01 → 1 → 日 → 田 → 土 → 地 → 空 → 色 → 7 → 1 → 一

汉字和英文，在“一、丨、十、0、1”里咬成同一个环。

留个钩子：0 = 2D

空，地也。

地 = D + 也

空 = 0 = 2D

Q 是 0 中间有一点，只是把里面的一点拿到右下角来了。

W 是山。

E 是山向右倒。

N 是旋转的 Z。

X 是两个 V，说到底也是山。

J 就是把 P 第二条线擦掉了。

S 就是丨或者 1 弄弯曲了。

有些话，先放在这里。留个钩子，给以后的人。

键盘上的 0 与 1

Q=0 W=0 E=1 R=0 T=10 Y=0 U=1 I=0 O=0 P=0
A=1 S=0 D=0 F=0 G=1 H=1 J=0 K=0 L=1
Z=0 X=0 C=0 V=0 B=0 N=0 M=0

上排的 1 在 3、5、7：E、T、U

中排的 1 在 1、5、6、9：A、G、H、L

下排全是 0。

Q 本质是 0，只是把中间一点写成一捺。

英文字母的 0/1 分布，可能和键盘位置、手指移动有关。

环里怎么走

一 伴丨 → 十

十 变一点 → 卜

卜 加一横两点 → 不

不 变一变 → 个

个 去竖变撇捺 → 人

人 上加一横 → 大

大 上再加一横 → 天

天 出头 → 夫

夫 收一横成日 → 日

日 加月 → 明

明 去月加生 → 星

星 去生加丨 → 田

田 下一横 → 土

土 上加一横 → 王

土 加也 → 地

地 拆开，土里有十，十里有丨，丨里有一。

主要偏旁咬合

亻（人字旁）
人 → 个 → 大 → 天 → 化 → 什 → 仁 → 仙 → 休 → 体

人旁的字，都是“人”在左边站着，和右边作伴。

氵（三点水）
一 → 十 → 土 → 地 → 池 → 河 → 海 → 洋 → 江 → 湖

水旁的字，是从“地”生出来的水，再流成江河湖海。

木（木字旁）
十 → 木 → 林 → 森 → 树 → 根 → 枝 → 叶 → 花 → 草

木从“十”长出来，木多成林，林多成森，再开花长草。

艹（草字头）
十 → 艹 → 花 → 茶 → 药 → 草 → 苗 → 芽 → 英 → 莲

草字头就是两个“十”并排，草木都从土里长出来。

口（口字旁）
一 → 丨 → 口 → 日 → 田 → 由 → 甲 → 申 → 电 → 申

口是横竖围成框，里面加横就成日、田、由、甲。

忄（心字旁）
心 → 忄 → 想 → 思 → 念 → 情 → 恨 → 怕 → 慌 → 忙

心旁的字，都是心里在动，不是拆字，是心动。

讠（言字旁）
言 → 讠 → 说 → 话 → 记 → 让 → 讲 → 课 → 读 → 诗

言旁的字，都和说话、文字有关，口里出来的东西。

扌（手字旁）
手 → 扌 → 打 → 找 → 把 → 拉 → 推 → 接 → 提 → 握

手旁的字，都是手在做动作，一提一放，都是手。

一横一竖，半半伴伴，全在里面转。
