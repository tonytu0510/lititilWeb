规则压缩与还原
示例版

压缩逻辑做成一个 JS 方法，命名 compressMethod。
前端只调它，规则写在页面上，不碰服务端。

一、输入原文
输入任意文字，点“压缩”试试。
二、压缩结果（短码）
短码 + 规则 = 可还原。
三、还原结果（原文）
当前为示例版，还原逻辑可替换。
四、规则说明（示例）
核心等式：一 = 丨 = 空 = 0
压缩：取原文每个字，按偏旁部首拆
归约：横归一，竖归丨，弯/圈/点归0
再归约：一、丨、0 统一转成空
短码：空的数量 + 位置，组成索引
还原：短码 + 规则 → 反向展开 → 原文
示例版：压缩方法是占位，规则可替换
