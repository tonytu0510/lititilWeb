规则压缩与还原
最小可跑框架

先跑通一轮，再换规则。
压缩：原文 → 短码；还原：短码 → 原文。

一、输入原文
输入任意文字，点“压缩”试试。
二、压缩结果（短码）
短码 + 规则 = 可还原。
三、还原结果（原文）
没规则，还原不出来。
四、当前规则（框架版）
  • → 规则：一 = 丨 = 空 = 0
  • → 压缩：取原文每个字的第一个笔画，横归 一，竖归 丨，其余归 0
  • → 再归约：一、丨、0 统一转成 空
  • → 还原：按规则反向展开
  • → 这是框架版，规则可以随时换
