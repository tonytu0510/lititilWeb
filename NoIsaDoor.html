No · 英文拆字

No 不只是否定，它里面藏着一个 and。

规则

No → N + O

N = and

O = 0 / 空

所以 No 后面，常常能拆成：

and + 俚语 / and + 反转动作

警示语拆解

原句 拆后 意思
No Smoking N sok and sucker
No U-turn N U-turn and U-turn
No Entry N entry and try
No Overtaking N over taking and over taking
No Trespassing N tres passing and trace passing
No Fly Zone N fly zone and fly zone
No Fireworks N fire works and fire works
No Sharp Objects N sharp objects and sharp objects
No Soliciting N so licit ing and so licit ing
No Refunds N re funds and re funds
No Smoking In Bed N smoking in bed and sucker in bed
No Shoes, No Shirt, No Service N shoes, N shirt, N service and shoes, and shirt, and service

大部分符合，不是全部。语言不是数学，能有大半命中，就不是巧合。

为什么用 No，不用 Not

Not = N + O + T

T = 一丨 = 十，太完整，太正式，不容易滑动。

No = N + O，是开着的口子。

所以警示牌偏爱 No，不是偶然。

No 不是墙，是门。
